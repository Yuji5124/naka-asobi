# ひなあそび

4〜7歳向けの、文字と形を指で触って遊ぶWebアプリ。HTML / CSS / JavaScriptだけで動き、ビルド・ログイン・外部API・有料サービスは不要です。教材タブレットの「触る → 試す → 即反応 → もう一度」という短いループを、オリジナルのUI・SVGイラスト・白い友達キャラクターで実装しています。

## タブレット向けの画面

横向きタブレット（1024×768〜1180×820）を基準にした画面です。ホームは青空・草原・家・池のオリジナルSVG風景、遊びの選択は4枚の大きな絵カード。遊びの画面は左〜中央に操作エリア、右に友達キャラクターと吹き出し、下にやり直し・次へボタンを置き、スクロールなしで操作できます。描画エリアは標準タブレットで400 CSS px以上、描線はクレヨン風です。縦向きタブレット・スマホでは縦配置に切り替わります。

風景とカードは解像度に依存しないSVGで作成しています。外部画像やフォントの読み込みはありません。

## 起動

```sh
cd /workspace/naka-asobi
python3 -m http.server 8000 --bind 0.0.0.0
```

ブラウザでポート8000を開きます。一般的な静的Webサーバーでも動作します。

## 遊び

ホーム → あそびをえらぶ → みつける → なぞる → つなぐ → かく → 結果 → ホーム。
選択画面からどの遊びにも入れます。対象は「あ・し・つ・く・へ・ほ」の6文字です。

- **みつける**：8枚のカードから「あ」を3個探します。間違いにも揺れと音で反応します。
- **なぞる**：「し・つ・く・へ」を選択。①から順に軌道の近くを通ると成功。書き始め・進行順・軌道の通過率で判定し、ただの落書きではクリアしません。
- **つなぐ**：横・曲がり・縦の道をドラッグして、文字を絵まで届けます。パーツをタップ → 空きマスをタップでも操作できます。T字を含む違うパーツは優しく再試行を促します。「ちがう もじ」で6種類の絵を選べます。
- **かく**：「ほ」を自由に書きます。3本以上の線・描画量・幅と高さ・領域・大まかな開始位置でゆるく判定。成功すると書いた線に目がつき、動きます。文字認識ではないため、形の正確さは判定しません。
- **ずかん**：遊んだ文字の読み・関連する絵・順に動く簡易書き順ガイドを表示します。ガイドは本格的な書写教材の代替ではありません。

Pointer Events対応。タッチ／マウスで同じ操作ができます。パズルはタップ方式も使えます。音はWeb Audio API、日本語読み上げはSpeechSynthesis。利用可能な日本語音声はOSとブラウザによって異なり、音声がなくても遊べます。

## かたちの遊び

「はじめる」→「かたち」から、写真の学習構造をもとにしたオリジナルの3種類の遊びを選べます。

- **まわす**：見本と同じ積み木を、矢印または横ドラッグで90度ずつ回転。見本と同じ向きになると成功します。回転中も見え方が変わります。
- **つむ**：黄色・青・緑の積み木を台にドラッグ、または色を選択して台／積み木をタップして重ねます。「ひとつもどす」で外せます。見本と同じ配置・色の組み合わせで成功。台の上で位置がずれていても同じ構造なら成功します。浮いた積み木は作れず、1列3段・全体12個まで置けます。台を横ドラッグ、または矢印で回すと見本も同じ方向に回り、隠れている部分を確認できます。
- **ならべる**：三角・四角・丸をシルエットへドラッグ、または形→置き場所をタップ。三角は「↻」で回せます。ロケット・家・車の3種類。違う形／向きなら優しく再試行を促します。

立体は `shapes.js` 内の座標と回転角からSVGの面を投影する独自の軽量レンダラーです。WebGLや3Dライブラリは不要。見本の向き合わせ・構造合わせを行う遊びで、物理シミュレーションや画像認識ではありません。各遊びには3問あり、次の問題／やり直し／ホーム移動ができます。

## 保存

`localStorage` の `hiragana-asobi-v1` に、遊んだ文字・クリアした遊び・最近遊んだ文字・スタンプ・音設定・遊んだかたちの種類のみ保存します。旧版の文字の記録を引き継ぎます。個人情報は保存しません。保存が禁止されたブラウザでも遊べますが、記録は次回に残りません。

## GitHub Pages

リポジトリの **Settings → Pages → Deploy from a branch** で `main` の `/ (root)` を選択してください。`index.html`、`style.css`、`shapes.css`、`app.js`、`shapes.js`、`favicon.svg`、`assets/` が配信されます。すべての参照を相対パスにしているため、`/naka-asobi/` 以下でも動作します。ビルドやルーターのフォールバック設定は不要です。GitHubへの反映後、Pagesの配信完了はGitHubのActions / Pages画面で確認してください。

## ブラウザ検証

起動した状態で、PlaywrightとChromiumが利用できる環境なら以下を実行できます。

```sh
node tests/playtest.cjs
node tests/shapes-playtest.cjs
```

テスト用Playwrightはアプリの実行には不要です。`CHROMIUM_PATH`（既定 `/usr/bin/chromium`）、`TEST_BASE_URL`（既定 `http://127.0.0.1:8000`）、`TEST_ARTIFACT_DIR`（既定 `/tmp/hiragana-playtest`）でテスト環境を切り替えられます。

横向きタブレットを初期画面にして操作を検証する場合：

```sh
TEST_VIEWPORT='{"width":1024,"height":768}' node tests/playtest.cjs
```

テストはタブレット横画面のスクロール不要・描画領域の大きさも確認します。実機のSafari/iPadOSやAndroid固有の挙動は、公開URLを端末で開いて確認してください。

`shapes-playtest.cjs` は回転・積み木のドラッグ／タップと取り消し・形合わせの向き・記録の互換性・タブレット／スマホ表示を検証します。
